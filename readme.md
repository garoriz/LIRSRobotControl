# Инструкция по сборке APK-файла (Android Studio)

---

## Шаг 1: Установка и настройка окружения

1. Скачайте установщик с [официального сайта](https://developer.android.com/studio)
2. Запустите установку, следуя инструкциям мастера
3. При первом запуске Android Studio автоматически скачает Android SDK

---

## Шаг 2: Клонирование репозитория

### Вариант B: Через терминал

## Шаг 3: Сборка Debug APK (можно пропустить, если нужно установить напрямую через Android Studio)

1. Откройте проект в Android Studio, если ещё не открыт (**File → Open** → папка проекта)
2. Дождитесь завершения синхронизации Gradle (прогресс виден внизу окна)
3. В верхнем меню выберите **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
4. Дождитесь завершения сборки
5. Во всплывающем уведомлении нажмите **locate**, чтобы открыть папку с APK

Готовый файл находится по пути:

```
app/build/outputs/apk/debug/app-debug.apk
```

---

## Шаг 4: Установка APK на устройство

### Через Android Studio

1. Подключите устройство по USB
2. Включите **Отладка по USB** в настройках разработчика на телефоне
3. Выберите устройство в Android Studio в выпадающем списке на верхней панели инструментов
4. Нажмите **Run ▶** (Shift + F10)

### Вручную

1. Скопируйте APK-файл на телефон
2. Откройте его через файловый менеджер
3. Разрешите установку из неизвестных источников при запросе

# Инструкция по подключению к АртБулу

1. Необходимо запустить Ubuntu c ROS Noetic
2. Помимо запуска необходимых пакетов для езды робота необходимо запустить rosbridge командой
   roslaunch rosbridge_server rosbridge_websocket.launch, чтобы приложение смогло подключиться. Если пакет не установлен, то необходимо установить: sudo apt install ros-noetic-rosbridge-suite
